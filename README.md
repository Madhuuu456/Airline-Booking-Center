# SkyRoute Air — Airline Booking Center

A modern multi-page airline booking frontend built with **HTML, CSS and JavaScript**.

## Pages / roles
1. Home — customer landing page
2. Flights — flight search and timing comparison
3. Booking — passenger details and booking flow
4. Confirmation — PNR/ticket confirmation
5. Admin Dashboard — admin role
6. Agent Portal — travel agent role
7. Flight Staff — operations/staff role
8. Customer Support — support role

## Features
- Responsive UI/UX
- Airline hero and destination imagery
- Multiple flight timings and fares
- Flight sorting
- Seat availability display
- Passenger form
- Demo booking + generated PNR
- Browser localStorage for booking state
- Admin, agent and flight-staff dashboards
- Mobile responsive layout

## Run
Open `index.html` in a browser.

This is a frontend demo. For production real-time booking, connect the JavaScript to a backend/API, database, authentication and a real payment gateway.
